# Governance, Security, And Human-In-The-Loop

Use this for security-aware AI automation, governance, access control, auditability, and the user's information security background.

## Profile Anchors

The user has:

- MSc specialization in Information Security.
- FlowPilot AI with risk classification, approved workflow templates, AI proposals, audit logs, RBAC, RLS, and human review.
- Gote Note with authenticated Q&A over only the logged-in user's notes.
- SharePoint permission and access-control work.
- Master's thesis on lightweight hybrid IDS for automotive CAN networks.
- Certifications and experience across Azure, Power Platform, AWS, and applied AI.

## Key Interview Themes

- AI should propose; humans approve in high-risk workflows.
- Retrieval and automation must respect permissions.
- Audit logs matter for trust, debugging, and compliance.
- Risk classification helps decide when to automate, escalate, or block.
- Security is both technical and process-oriented.
