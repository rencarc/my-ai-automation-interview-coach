# Failure Or Rejection Postmortem

Use this after a weak interview, rejection, or uncertain outcome.

## Goal

Separate controllable improvement areas from role mismatch or external factors.

## Inputs To Ask For

- role and company type,
- interview stage,
- questions asked,
- answers given,
- where the user felt weak,
- feedback from recruiter/company,
- whether there was a take-home or technical case,
- final outcome.

## Diagnosis Categories

| Category | Signals | Next action |
|---|---|---|
| Skill gap | could not answer technical depth | targeted drills |
| Expression gap | knew content but unclear/too long | English/pacing practice |
| Evidence gap | claimed experience but no concrete proof | rebuild story/project depth |
| Role mismatch | role expected different stack/seniority | adjust target roles |
| Process issue | weak take-home/README/timing | improve workflow |
| External | no feedback, hiring freeze, internal candidate | do not overfit |

## Postmortem Output

```text
Likely primary cause:
Secondary causes:
Evidence:
What not to overlearn:
Next 3 drills:
Resume/JD positioning change:
Follow-up message recommendation:
```

## Follow-Up Message Template

```text
Hi [Name],

Thank you for the opportunity to interview for [role]. I appreciated learning more about [team/company area].

If you are able to share any feedback, I would be grateful, especially on where I could strengthen my technical or communication fit for similar roles in the future.

Thanks again,
Zhen
```

Keep it short. Do not argue with the decision.
